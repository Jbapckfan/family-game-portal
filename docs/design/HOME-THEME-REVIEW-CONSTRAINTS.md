# Home theme is the visual baseline

James's November 6, 2026 correction to the Opus design commission: “these don't follow the basic style of the overall website, so they are distracting. follow the overal theme of the website/background and colors we are using on the main page, try again”.

For this design review, the live public home at `/alford-daily/` is authoritative. Alternative layouts must stay within its visual identity. The earlier brief's generic cool-blue/white frame was incorrect and is superseded.

Measured home tokens:

| Role | Value |
| --- | --- |
| Page paper | `#f6f3ec`, solid, no gradient |
| Card surface | `#fffefa` |
| Main ink | `#202c35` |
| Muted text | `#5b666c` |
| Fine border | `#dcded8` |
| Green accent | `#376c58` |
| Display/brand | bundled DM Serif, normal weight |
| Body/controls | bundled DM Sans |
| Main card corners | 22px |

Use the existing logo/wordmark, paper field, warm-white surfaces and restrained borders/shadows. Do not introduce a competing page palette, typography or gadget theme. Game board colors that encode rules (Circuit quadrants, Territory blue/amber, Hunch black/white, Sprout foliage) remain localized and distinguishable. Alternatives may change arrangement, hierarchy, pieces and interaction presentation while preserving these shared rules.

The cream paper is specifically the current home reference; this does not authorize a new brown or purple game theme. Gameplay, keeper rankings and actual player pages are unaffected by the mockup revision. Implementing a chosen design is a separate subsequent step.

Reference captures, computed browser styles, exact CSS and model receipts are recorded with the second-round design studio evidence. All final proposals must be checked at phone and desktop widths for theme equality, loaded fonts and readable layout; CSS token presence alone is insufficient.
