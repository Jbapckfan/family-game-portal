James’s only Cairn feedback so far was: “the perfect summit image looks really dumb and stands out.” That is recorded as graphic feedback; enjoyment, replay, rating, keeper disposition and relative rank remain unset. Morph follows Cairn after James’s response.

The finish screen now uses restrained typography, a small blue five-mark motif and explicit results. Portrait and square PNGs contain identical abstract marks and aggregate data, with no words, rack letters, slot positions, per-level status pattern or URL. The local answer list is excluded from sharing. Native text is offered first; web file sharing, cancellation, PNG download, real clipboard success and a selectable-caption fallback are supported. Physical share sheets and native image sharing remain unverified.

The engine, hook rules, progress/storage schema, published bank, dictionaries, calendar and practice reservation logic are unchanged.
