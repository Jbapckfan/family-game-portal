# Sprout: answers become the plant

James rejected the three separate plant-window concepts: “i don't like any. i want the answers to be part of the plant”. This is the design requirement. Completed answers must physically form the plant rather than live in a separate history list.

A: each whole word is part of a large leaf. B: each letter occupies a leaf and the word grows into a branch. C: the word letterforms themselves form a living vine. B is the assistant recommendation for a readable connection between letter input and plant growth, not a selected user preference. All are concept images; gameplay, stage artwork and touch/keyboard entry still need a selected implementation. No new design is published by this concept pass.

The images use the same illustrative CAT/CATS/CASTS state. Open index.html to compare/enlarge. PROMPTS.md records the built-in tool prompts. Originals remain in the generated-images folder.
