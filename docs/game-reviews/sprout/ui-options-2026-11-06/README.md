# Sprout: natural plant UI concepts

James: “the sprout Ui is still weird, show me several more options”. The published SVG word-ladder climber remains unaccepted. These concepts explore a substantially different composition with the plant separate from word controls. They do not imply a keeper verdict, score or approved design.

- **A — Botanical window:** a whole natural-looking plant and ceramic pot, with word history and input below. Assistant recommendation for the clearest growth reward.
- **B — Living trellis:** climbing vine, architectural support and a separate progress column.
- **C — Growth close-up:** macro leaves and a bud as the visual reward, with a separate progress rail.

All retain the pale blue collection background, white controls, readable sans-serif typography and the existing word challenge. The sample CAT → CATS → CASTS with remaining E/R/T is illustrative, not James’s daily puzzle. The target is six letters, with three growth steps remaining. Static mockups do not demonstrate animation or game logic; any selected implementation must bind artwork and controls to actual state and preserve exact rules and saved progress.

Generated with the built-in image tool. The shared prompts and targeted corrections are in `PROMPTS.md`. A uses a text-only five-wilts status to avoid incorrect generated marker counts. C’s stage rail was corrected to six labelled stages (3–8), with stage 5 current. Original and superseded tool outputs remain in the generated-images directory; only the final three are copied here.

Open `index.html` for the side-by-side comparison and enlarged images. No live game was changed by this concept pass.
