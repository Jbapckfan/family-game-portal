## Playing

Follow the clue to form a nine-letter word on the 3×3 board. Consecutive tiles must touch horizontally, vertically or diagonally, and a tile can be used only once. Tap an earlier selected tile to shorten the path, or use Undo/Clear. Submit with Check trail. Keyboard arrow keys move tile focus; Space or Enter selects; Backspace undoes and Escape clears. There is no timer.

Trail accepts clue-specific prepared answers, not every word in a general dictionary. The underlying shared runtime retains separate Daily/Practice results and spoiler-free sharing. An additional accepted spelling or valid alternative clue solution would require editorial verification rather than automatic corpus admission.

## Difficulty feedback

James: “trail seems way too easy.”

The current rules require a nine-letter word using all nine board tiles. The prepared-path tests confirm the answer occupies the whole grid, so no tile is a decoy. The visible daily uses a direct definition clue. The design concern is that recognizing the word can leave mostly tracing; this is a source-informed assessment, not a measured difficulty score across human players.

Recommendation for a separate sample: retain one clued word, use a 4×4 grid with extra decoy letters and meaningful false starts, give a less direct clue first, and offer the full definition as an optional hint. The extra letters should create route choices; merely expanding spacing or using obscure vocabulary would not address the complaint. A sample would need explicit solvability and accepted-answer checks before showing it.
