# Alford Daily privacy and support preparation draft

This is a completion brief for the final release. It cannot be published unchanged: the final website host, support contact, retention periods, intended age audience and ad/payment integrations must be identified first.

## Current product facts

The web games keep detailed Daily/Practice progress and preferences in browser storage. The native app keeps game state in its WebKit data store and its record/preferences ledger in UserDefaults. Web and iPhone records are separate. There is no configured player account or cross-device score service. Clearing storage or deleting the app can remove local progress; operating-system backup behavior is separate.

The native app offers optional local reminders and haptics. Its normal build has purchases disabled. The existing collection has no configured advertising SDK. Adding ads, analytics, payments or remote accounts changes the disclosure and requires a new data inventory; local game saves do not establish that a future release collects no data.

The public web host can receive network information such as IP address and requested URL. Confirm its actual logging, processors, locations and retention before finalizing the policy. Result sharing opens user-controlled sharing/copy actions; the selected destination's data practices are separate.

## Support page copy after contact is confirmed

**Need help with a puzzle?**

Tell us the game, the puzzle's displayed date/number, what you tried and what happened. For a rejected word, include the word and the rule message. A screenshot is optional. Please tell us whether you are using the website or iPhone app and which version you see.

**Where is my progress?**

Website progress belongs to the browser and address where you played. The iPhone app keeps its own local progress. Switching browser, using private browsing, clearing website data or deleting the app can affect what is available. There is no account-based cross-device sync in this release.

**How do Daily and Practice work?**

Daily changes at midnight Central Time. Practice is separate from Daily records. The collection contains prepared puzzles; puzzle rules, help and any assistance are shown within each game.

**How do I report a result or purchase problem?**

Include the game/date and outcome you expected. For a purchase issue, use the app's Restore Purchases action when available and contact the confirmed support address with the storefront and product name. Do not request passwords, full payment details or authentication codes.

**Support contact**

Insert the verified monitored contact and response expectations before publishing. Do not promise a response time that has not been staffed.
