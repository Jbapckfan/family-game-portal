## Shared runtime compatibility

`mountDailyGame` keeps the same public configuration, callback and return APIs. Regular rerenders now restore a focused control by its ID or data identity; if a consumed tile no longer exists, focus stays on the puzzle container. A playing-to-terminal transition focuses the result instead of leaving focus on removed/disabled controls. Cipher and Split's post-commit helpers respect this terminal focus.

Only a hint rerender preserves text inputs whose markup has no engine-owned `value` attribute (Hive/Rung). A submitted word or mode change is not carried forward by that path. Inputs backed by engine state keep their normal state-derived values, including costed hint prefixes. No session-controller change or persistence-key migration was required. The Qwen family consumes the same runtime; root was informed about the terminal-focus contract and source-only test allowlist.
