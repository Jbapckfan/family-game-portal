  • Each code stands for one different real letter.

Concept notes: the message is set like type — big guess letters over small code letters, real word spacing, no boxed tiles. Selecting a code tints every occurrence and the side panel states how often it appears. Encoded phrase, clue and the two givens (H→T, J→E) are today's supplied state; assignments here are local and unchecked.
