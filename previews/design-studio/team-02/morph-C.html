Pick one column, then type or tap its new letter.

Concept notes: the goal is spelled under every column, so "which letters still differ" is readable at a glance (green rule = column already matches). Columns are live here: select one and tap a key. Keyboard keys are 48px tall but narrower than 44px on a 320px phone, like a system keyboard; physical typing would remain the primary path on desktop. The selected column is outlined in ink so green only ever means "matches the goal". Prototype wiring: column select, on-screen keys, Reset and ⌫ work; physical typing, Check, Undo, the route hint and Give up are visual only.
