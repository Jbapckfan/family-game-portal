# DeepSeek source provenance

Both supplied files are preserved byte for byte in `original/`. The six ideas and the SwiftUI hub starter are credited to DeepSeek. No exact model version was provided.

The Swift file references `TwinHiveView`, `SpareView`, `RungView`, and `SpecView`, but defines none of them. Cipher, Trail, and Split have only catalog taglines; the pasted claim of fully interactive screens is not supported by the supplied code. The hub also displays a fixed 12-day streak, and the sample lexicon has only 20 words. The date uses the device calendar and the hash multiplier is not the FNV-1a prime. This starter is not a compilable six-game app.

ChatGPT completed the engines, authored finite puzzle banks and clues, built playable web screens, and integrated all six into Alford Daily. The visible credit is **Concept by DeepSeek · Built by ChatGPT**. Original source attribution is retained separately from completion work. The uploaded Swift `@main` is preserved as reference source, not added as a second application entry point.

The completed games use the shared Central-time calendar, namespaced state, trusted native bridge, and offline iOS resource pipeline. Their word lists and clues were authored for this integration; the incomplete starter did not supply playable puzzle banks. No new third-party dictionary is imported.
