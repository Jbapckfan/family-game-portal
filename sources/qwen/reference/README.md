# HEX MIND: The Ultimate Daily Puzzle Suite

**Tagline:** Six Daily Workouts for Your Brain.

This package contains the conceptual blueprints, technical specifications, and playable prototypes for **HEX MIND**, a mobile app featuring six distinct cognitive games designed to maximize retention through varied mental loads.

## Contents

1. **QUADRA.html**: A fully functional single-file web prototype for Game 1 (Category-based Anagram Solver).
2. **GAME_BLUEPRINTS.md**: Detailed mechanics, psychology, and design specs for all 6 games.
3. **iOS_ARCHITECTURE.md**: Technical stack, data models, and monetization strategy for the native iOS app.
4. **CODE_SNIPPETS/**: Reference implementations for key components in SwiftUI/Swift.

## How to Use

- Open `QUADRA.html` in any modern browser to play the first game immediately.
- Review `GAME_BLUEPRINTS.md` for the full product vision.
- Use `iOS_ARCHITECTURE.md` as the foundation for development.
